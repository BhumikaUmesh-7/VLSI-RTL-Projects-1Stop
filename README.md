# VLSI RTL Projects – 1Stop Training & Internship

This repository contains my hands-on VLSI/RTL projects completed during my 1Stop training and internship.

The projects gave me practical exposure to SystemVerilog, RTL design, finite state machines, testbench development, simulation, waveform analysis, pipelining, forwarding and hazard detection.

## Projects

### 1. Sequence Detector

A SystemVerilog sequence detector for detecting the `1010` pattern.

Topics covered:
- FSM design
- Mealy FSM
- Moore FSM
- Overlapping sequence detection
- Non-overlapping sequence detection
- Testbench development
- Simulation and waveform analysis

Folder:
`01_Sequence_Detector`

---

### 2. Vending Machine

A SystemVerilog FSM-based vending machine controller.

Features include:
- Product selection
- Multiple products
- Cash payment
- Online payment
- Product dispensing
- Change/refund handling
- Transaction cancellation

Folder:
`02_Vending_Machine`

---

### 3. 16-Bit RISC Processor

A custom 16-bit RISC-style processor implemented in SystemVerilog.

Features include:
- 5-stage pipeline
- IF – Instruction Fetch
- ID – Instruction Decode
- EX – Execute
- MEM – Memory
- WB – Write Back
- Forwarding
- Hazard detection
- Register file
- Custom RISC-style instruction set

Folder:
`03_16_Bit_RISC_Processor`

> Note: This project is a custom 16-bit RISC-style processor. It is not an official RISC-V implementation.
